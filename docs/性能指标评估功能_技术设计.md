# 目标性能指标评估功能技术设计

## 1. 文档目的

本文定义真值对比功能中 Dx、Dy、Vx、Vy、Ax、Ay 性能指标的功能边界、计算口径、结果模型、可视化方式和验收要求，为后续开发、测试及需求确认提供统一依据。

本文只描述性能评估能力，不改变雷达与 RTK 的文件解析、目标关联、时间延迟检测和时空对齐算法。

## 2. 功能目标

在雷达数据与 RTK 真值完成对齐后，系统应当：

1. 按 RTK 真实纵向距离将有效样本划分为六个距离段；
2. 分别计算 Dx、Dy、Vx、Vy、Ax、Ay 的逐帧误差；
3. 对 Dx、Dy、Vx、Vy、Ax 计算每个距离段的样本数、误差 RMSE、准确率和连续三帧指标；Ay 按完整曲线计算样本数、RMSE及最大绝对误差；
4. Dx、Dy、Vx、Vy、Ax 根据准确率及连续三帧指标给出结论；Ay 根据绝对误差是否超过 `1m/s²` 给出结论；
5. 在界面中清楚展示失败项目、失败原因和对应违规帧；
6. 支持将逐帧判定明细和区间汇总结果导出。

## 3. 功能边界

### 3.1 本期范围

- Dx：纵向距离精度；
- Dy：横向距离精度；
- Vx：纵向速度精度；
- Vy：横向速度精度；
- Ax：纵向加速度精度；
- Ay：横向加速度误差，仅按 `abs(Ay_radar - Ay_truth) ≤ 1m/s²` 评判；
- 六个纵向距离段的独立统计；
- RMSE、准确率、连续三帧指标和区间结论；
- 总体结论、区间表格、阈值曲线及违规帧标记；
- 评估结果导出。

### 3.2 不在本期范围

- 修改雷达与 RTK 的关联、插值、坐标转换和延迟补偿算法；
- 使用 RMSE 作为合格判据。当前需求没有定义 RMSE 限值；
- 自动推断缺失的单位或真值字段；
- 将不同目标、不同生命周期或数据中断两侧的帧拼接为连续帧；
- 使用雷达测量距离决定样本所属距离段；
- 将二维位置误差 `sqrt(Dx_error² + Dy_error²)` 代替 Dx 或 Dy 的单轴误差。

## 4. 术语与符号

| 符号 | 含义 |
|---|---|
| `d` | RTK 真实纵向距离的绝对值，`abs(Dx_truth)` |
| `q_i` | 第 i 帧当前物理量的 RTK 真值 |
| `x_i` | 第 i 帧当前物理量的雷达测量值 |
| `s_i` | 有符号误差，`x_i - q_i` |
| `e_i` | 绝对误差，`abs(x_i - q_i)` |
| `T_i` | 第 i 帧普通精度阈值 |
| `L_i` | 第 i 帧连续三帧最大误差阈值 |
| `r_i` | 连续三帧归一化误差，`e_i / L_i` |
| `R3` | 一个距离段内的连续三帧指标值 |

所有百分比真值阈值都以对应真值的绝对值计算。例如 Vx 的 `3%真实值` 应计算为 `0.03 × abs(Vx_truth)`，防止负速度产生负阈值。

## 5. 数据前提

### 5.1 必需数据

每个参与评估的对齐样本至少应具有：

- 目标或轨迹标识；
- 生命周期或轨迹段标识；
- 雷达帧号；
- 雷达时间戳；
- RTK 真实纵向距离；
- 当前物理量的雷达值与 RTK 真值；
- 时空匹配状态；
- 数据中断识别所需信息。

### 5.2 有效样本

一个样本只有在下列条件均满足时才能进入误差统计：

- 已通过现有时空对齐及匹配门控；
- 雷达值和真值均为有限数值；
- 两个字段单位兼容且已完成明确映射；
- RTK 真实纵向距离位于 `[0, 150]m`；
- 样本属于当前选中的目标、轨迹段和数据文件。

### 5.3 匹配失败帧

匹配失败帧无法计算误差，不进入 RMSE 和条件准确率计算，但必须单独统计匹配覆盖率：

```text
匹配覆盖率 = 有效匹配帧数 / 应评估帧数
```

匹配覆盖率只用于说明原始帧中有多少帧成功获得了可比较的雷达值和真值，不参与通过/不通过判定。例如 1000 帧中有 990 帧完成匹配，则匹配覆盖率为 99%。

## 6. 距离分段

所有物理量统一使用 RTK 真实纵向距离 `d` 分段：

| 编号 | 距离段 |
|---|---|
| D1 | `[0, 10)m` |
| D2 | `[10, 20)m` |
| D3 | `[20, 50)m` |
| D4 | `[50, 70)m` |
| D5 | `[70, 100)m` |
| D6 | `[100, 150]m` |

最后一个区间包含 150m。禁止使用雷达 `Dx` 分桶，否则边界附近样本会因测量误差被分配到错误区间。

## 7. 通用统计口径

### 7.1 样本数

样本数为当前物理量、当前距离段内可以计算误差的有效匹配帧数。不同物理量可能因字段缺失或无效值而具有不同样本数。

### 7.2 RMSE

```text
RMSE = sqrt(mean(s_i²))
```

RMSE 是区间内误差的描述性汇总指标，不是单帧误差，也不参与当前通过判定。

计算和判定应使用未四舍五入的值，界面显示值建议保留三位小数。

### 7.3 准确率

逐帧普通精度合格条件：

```text
e_i < T_i
```

区间准确率：

```text
准确率 = 普通精度合格帧数 / 有效样本数 × 100%
```

准确率判定：

```text
准确率 > 95.45%：通过
准确率 ≤ 95.45%：不通过
```

需求使用严格小于和严格大于，因此误差恰好等于阈值时该帧不合格，准确率恰好等于 95.45% 时区间不通过。

### 7.4 连续三帧指标

需求语义为：不允许存在连续三帧的绝对误差同时大于或等于各帧对应限值。

对于每个连续三帧窗口：

```text
r_i = e_i / L_i
窗口共同误差 = min(r_i, r_(i+1), r_(i+2))
```

当前距离段的连续三帧指标：

```text
R3 = max_i(min(r_i, r_(i+1), r_(i+2)))
```

判定：

```text
R3 < 1：通过
R3 ≥ 1：不通过
```

`R3` 的意义是最严重连续三帧窗口相对于各自限值的最大共同误差。该归一化定义同时适用于固定限值和随真值变化的动态限值。

界面建议显示为 `0.84×限值` 或 `1.13×限值`。悬浮信息同时显示对应三帧的时间、帧号、误差、限值及窗口内最大单帧误差。

### 7.5 连续帧定义

三帧必须同时满足：

- 属于同一目标和同一生命周期；
- 按雷达时间戳或帧号顺序相邻；
- 中间不存在匹配失败帧；
- 中间不存在数据中断；

跨目标、跨生命周期或跨数据中断时，连续计数必须重新开始。跨越距离段边界不打断连续关系：只要是完整曲线中相邻的三帧，就参与连续三帧检测，每帧分别使用其所在距离段对应的限值。跨距离段的违规窗口归入中间帧所在的距离段，便于在分距离表中定位且避免重复计数。

例如连续三帧的真实纵向距离为 `49.9m、50.1m、50.3m`，它们仍是连续三帧：第一帧使用 20–50m 规则，后两帧使用 50–70m 规则；该窗口的统计结果归入中间帧所在的 50–70m 区间。

### 7.6 区间结论

在规则完整且具有有效样本时：

```text
区间通过 = 准确率 > 95.45% 且 R3 < 1
```

状态枚举：

| 状态 | 条件 |
|---|---|
| 通过 | 准确率及连续三帧指标均通过 |
| 不通过 | 任一判定指标不通过 |
| 不可判定 | 无有效样本、规则缺失或必需字段不可用 |
| 样本不足 | 有效样本少于3帧，不出具通过或不通过结论 |

总体结论采用完整曲线判定：任何一个有数据且可评估的距离段不通过，则当前物理量整体不通过；没有失败区间，但完整曲线涉及的任一距离段少于3个有效样本时，不出具整体结论；其余情况下，所有有数据区间均通过才判定当前物理量通过。完整曲线没有覆盖到的距离段显示“无数据”，不参与总体结论。

## 8. 各物理量规则

### 8.1 Dx：纵向距离精度

`e = abs(Dx_radar - Dx_truth)`。

| 距离段 | 普通精度阈值 `T` | 准确率 | 连续三帧阈值 `L` |
|---|---|---|---|
| 0–10m | `max(0.3m, 0.01×d)` | `>95.45%` | `0.5m` |
| 10–20m | `max(0.3m, 0.01×d)` | `>95.45%` | `0.5m` |
| 20–50m | `0.02×d` | `>95.45%` | `1.5m` |
| 50–70m | `0.02×d` | `>95.45%` | `0.05×d` |
| 70–100m | `0.02×d` | `>95.45%` | `0.07×d` |
| 100–150m | `0.025×d` | `>95.45%` | `0.10×d` |

其中 20–50m 的 `1.5m` 是固定限值，表示该距离段的最大连续三帧误差必须在 1.5m 以内，不随真实距离变化。

### 8.2 Dy：横向距离精度

`e = abs(Dy_radar - Dy_truth)`，距离段仍按真实纵向距离划分。

| 距离段 | 普通精度阈值 `T` | 准确率 | 连续三帧阈值 `L` |
|---|---|---|---|
| 0–10m | `0.2m` | `>95.45%` | `0.3m` |
| 10–20m | `0.3m` | `>95.45%` | `0.6m` |
| 20–50m | `0.3m` | `>95.45%` | `0.6m` |
| 50–70m | `0.6m` | `>95.45%` | `1.2m` |
| 70–100m | `0.6m` | `>95.45%` | `1.2m` |
| 100–150m | `1.0m` | `>95.45%` | `2.1m` |

### 8.3 Vx：纵向速度精度

`e = abs(Vx_radar - Vx_truth)`，`v = abs(Vx_truth)`。

| 距离段 | 普通精度阈值 `T` | 准确率 | 连续三帧阈值 `L` |
|---|---|---|---|
| 0–10m | `max(0.3m/s, 0.03×v)` | `>95.45%` | `max(1m/s, 0.05×v)` |
| 10–20m | `max(0.3m/s, 0.03×v)` | `>95.45%` | `max(1m/s, 0.05×v)` |
| 20–50m | `max(1m/s, 0.03×v)` | `>95.45%` | `1.4×max(1.5m/s, 0.05×v)` |
| 50–70m | `max(1m/s, 0.04×v)` | `>95.45%` | `1.4×max(1.5m/s, 0.05×v)` |
| 70–100m | `max(1m/s, 0.05×v)` | `>95.45%` | `1.5×max(1.5m/s, 0.07×v)` |
| 100–150m | `max(1m/s, 0.07×v)` | `>95.45%` | `1.5×max(1.5m/s, 0.10×v)` |

### 8.4 Vy：横向速度精度

`e = abs(Vy_radar - Vy_truth)`。

| 距离段 | 普通精度阈值 `T` | 准确率 | 连续三帧阈值 `L` |
|---|---|---|---|
| 0–10m | `0.3m/s` | `>95.45%` | `0.52m/s` |
| 10–20m | `0.3m/s` | `>95.45%` | `0.52m/s` |
| 20–50m | `0.3m/s` | `>95.45%` | `0.52m/s` |
| 50–70m | `0.5m/s` | `>95.45%` | `1.04m/s` |
| 70–100m | `0.5m/s` | `>95.45%` | `1.04m/s` |
| 100–150m | `0.8m/s` | `>95.45%` | `1.3m/s` |

### 8.5 Ax：纵向加速度精度

`e = abs(Ax_radar - Ax_truth)`，`a = abs(Ax_truth)`。

| 距离段 | 普通精度阈值 `T` | 准确率 | 连续三帧阈值 `L` |
|---|---|---|---|
| 0–10m | `max(0.3m/s², 0.05×a)` | `>95.45%` | `1.4×max(0.5m/s², 0.08×a)` |
| 10–20m | `max(0.3m/s², 0.05×a)` | `>95.45%` | `1.4×max(0.5m/s², 0.08×a)` |
| 20–50m | `max(0.5m/s², 0.08×a)` | `>95.45%` | `1.5×max(1m/s², 0.12×a)` |
| 50–70m | `max(0.5m/s², 0.08×a)` | `>95.45%` | `1.5×max(1m/s², 0.12×a)` |
| 70–100m | `max(1m/s², 0.12×a)` | `>95.45%` | `1.6×max(1.5m/s², 0.15×a)` |
| 100–150m | `max(1m/s², 0.12×a)` | `>95.45%` | `1.6×max(1.5m/s², 0.15×a)` |

### 8.6 Ay：横向加速度精度

Ay 只有一个评判指标，不按距离段设置准确率或连续三帧要求：

```text
abs(Ay_radar - Ay_truth) ≤ 1m/s²
```

判定方式：完整曲线内所有有效 Ay 样本的绝对误差均不超过 `1m/s²` 时通过；任意一帧超过 `1m/s²` 时不通过；无有效样本时不可判定。Ay 可以附带显示样本数和 RMSE，但 RMSE 不参与判定。Ay 不使用六段准确率表和连续三帧指标。

## 9. 结果数据模型

### 9.1 逐帧结果

建议为每个物理量生成以下字段：

```text
track_id
segment_id
radar_frame
timestamp
distance_bin
truth_distance
radar_value
truth_value
signed_error
abs_error
normal_limit             # Ay使用1m/s²
normal_pass
three_frame_limit        # Ay为空
normalized_severe_error  # Ay为空
three_frame_window_id    # Ay为空
three_frame_violation    # Ay为空
```

### 9.2 区间汇总结果

```text
metric                 # Dx/Dy/Vx/Vy/Ax/Ay
distance_bin
sample_count
rmse
normal_pass_count
accuracy
accuracy_requirement     # Ay为空
accuracy_pass            # Ay为空
three_frame_index        # R3，Ay为空
three_frame_pass         # Ay为空
violation_window_count
longest_violation_run
worst_window_start
worst_window_end
max_error_in_worst_window
status
failure_reasons
```

### 9.3 结论原因

`failure_reasons` 应支持多个原因，例如：

```text
["准确率未达到95.45%", "存在连续4帧严重超限"]
```

不能只返回一个布尔值，否则界面和导出结果无法解释失败原因。

## 10. 界面设计

### 10.1 总体布局

保持当前真值对比页面三栏结构：

- 左侧：文件、映射、目标和对齐配置；
- 中间：雷达/真值曲线和误差阈值图；
- 右侧：总体结论、分距离验收表和导出操作。

### 10.2 物理量切换

右侧验收表提供 Dx、Dy、Vx、Vy、Ax、Ay 切换。只有映射成功、单位兼容且具有有效真值的物理量可选择。Dx、Dy、Vx、Vy、Ax 显示六段验收表；Ay 显示完整曲线的样本数、RMSE、最大绝对误差、限值 `≤1m/s²` 和结论。

### 10.3 分距离验收表

统一列结构：

| 距离段 | 样本数 | RMSE | 准确率 | 要求 | 连续三帧指标值 | 限值 | 结论 |
|---|---:|---:|---:|---:|---:|---:|---|
| 20–50m | 3901 | 0.410m | 96.80% | >95.45% | 0.81× | <1.00× | 通过 |
| 50–70m | 120 | 0.520m | 94.90% | >95.45% | 1.12× | <1.00× | 不通过 |

展示规则：

- 通过：绿色状态；
- 不通过：红色状态，并标红具体失败单元格；
- 样本不足：黄色状态，不出具通过或不通过结论；
- 无数据或规则不完整：灰色“不可判定”；
- RMSE 只展示，不使用通过/失败色；
- 动态连续三帧阈值统一显示归一化倍数，悬浮时显示原始误差与原始阈值。

### 10.4 中间图表

每个物理量至少支持：

1. 雷达值与真值时间序列；
2. 绝对误差时间序列；
3. 普通精度动态阈值 `T_i`；
4. 连续三帧动态阈值 `L_i`；
5. 普通误差失败帧标记；
6. 连续三帧违规区间背景标记；
7. 悬浮信息：时间、帧号、距离段、雷达值、真值、误差、两个阈值及判定。

### 10.5 总体结论

建议显示：

- 当前物理量总体结论；
- 通过区间数/有数据区间数；
- 有效样本总数；
- 匹配覆盖率；
- 不通过区间数量；
- 连续三帧违规区间或窗口数量。

## 11. 配置边界

所有阈值应配置化，不应散落在回调或界面代码中。建议规则配置至少包含：

```yaml
metric: Dx
unit: m
distance_bin: [0, 10]
normal_limit:
  mode: max_absolute_percent
  absolute: 0.3
  percent: 0.01
accuracy_operator: ">"
accuracy_requirement: 0.9545
three_frame_limit:
  mode: absolute
  absolute: 0.5
three_frame_operator: "<"
```

需要支持的阈值模式：

- 固定绝对值；
- 真值百分比；
- `max(固定值, 真值百分比)`；
- 系数乘以 `max(固定值, 真值百分比)`。

配置加载时应校验：距离区间连续且不重叠、单位存在、百分比非负、倍率大于零、准确率位于 `[0,1]`。

## 12. 与现有项目的衔接建议

### 12.1 计算层

现有 `comparison/alignment.py` 已生成逐帧对齐结果，并提供分距离 RMSE、Mean、Max 统计。建议保留通用统计函数，新增独立的性能评估模块或函数，避免把验收规则耦合进基础对齐逻辑。

现有分桶使用雷达 `Dx`，性能评估必须改为独立使用 RTK `center_x` 真值分桶；原通用统计是否改变应单独评估，避免影响已有行为。

### 12.2 展示层

现有 `components/stats_panel.py` 可继续承载右侧表格，但性能评估表不应复用当前仅包含 RMSE、Mean、Max 的数据结构。

现有 `components/comparison_charts.py` 支持误差散点和固定阈值水平线；新增指标需要支持逐帧变化的阈值曲线和违规区间高亮。

### 12.3 回调与缓存

性能指标应在一次对齐完成后基于完整 `aligned_df` 统一计算并缓存。切换物理量只读取已缓存结果，不应重新执行目标关联和时空对齐。

### 12.4 导出

建议提供两级导出：

- 汇总 CSV/JSON：每个物理量、每个距离段一行；
- 逐帧 CSV：包含原始值、误差、阈值和通过状态，便于复核。

## 13. 异常与边界处理

| 场景 | 处理方式 |
|---|---|
| 距离段无样本 | 显示“无数据/不可判定”，不得显示通过 |
| 距离段仅 1–2 帧 | 可显示样本数、RMSE和准确率，但该区间及整体均不出具结论 |
| 真值为零 | 百分比项为零，但 `max` 中的固定下限仍有效 |
| 真值为负 | 百分比基于绝对值计算 |
| 误差等于普通阈值 | 单帧不合格 |
| 准确率等于 95.45% | 区间不通过 |
| 归一化误差等于 1 | 该帧达到严重误差限值 |
| 连续三帧归一化误差均 ≥1 | 连续三帧指标不通过 |
| 中间一帧小于 1 | 不构成连续三帧违规 |
| 中间一帧未匹配 | 连续计数中断 |
| 跨生命周期或数据中断 | 连续计数中断 |
| 连续三帧跨距离段 | 保持连续，每帧使用自身距离段限值；窗口归入中间帧所在距离段 |
| 单位不兼容 | 禁止计算，显示映射或单位错误 |
| Ax/Ay 真值缺失 | 对应指标不可用，不影响其他物理量计算 |

## 14. 测试与验收

### 14.1 单元测试

至少覆盖：

1. 六个距离边界的归属，特别是 10、20、50、70、100、150m；
2. 固定阈值、百分比阈值、Max 阈值和倍率 Max 阈值；
3. 正负速度、正负加速度及真值为零；
4. 误差与阈值相等时按失败处理；
5. 准确率与 95.45% 相等时按失败处理；
6. 三帧全部达到限值时 `R3≥1`；
7. 三帧中任意一帧低于限值时不构成违规；
8. 动态限值三帧的归一化计算；
9. 数据中断、未匹配帧和生命周期切换会中断连续计数，跨距离段不会中断；
10. 无样本、1帧、2帧时的不可判定状态；
11. RMSE 使用有符号误差平方计算且不参与结论；
12. 不同物理量的无效值不会相互污染样本数。

### 14.2 示例

固定限值 `L=0.5m`：

| 三帧误差 | 窗口共同误差 | 判定 |
|---|---:|---|
| 0.51、0.62、0.55m | `min(1.02,1.24,1.10)=1.02` | 不通过 |
| 0.51、0.48、0.60m | `min(1.02,0.96,1.20)=0.96` | 通过 |
| 0.80、0.80、0.10m | `min(1.60,1.60,0.20)=0.20` | 通过 |

### 14.3 集成验收

- 执行一次对齐后可以切换六个物理量而不重新对齐；
- 表格数值与导出汇总一致；
- 图上的失败帧与逐帧导出一致；
- 点击或悬浮违规区间可以定位对应原始帧；
- 任一区间失败时总体结论与失败原因正确；
- 无数据区间不会被计算为通过区间。

## 15. 性能要求

- 统计必须基于完整原始对齐数据，不能使用图表降采样数据；
- 优先使用向量化数组计算阈值、误差及准确率；
- 连续三帧指标可通过长度为 3 的滚动最小值和区间最大值计算；
- 对齐后一次性计算全部可用物理量并缓存；
- 图表可以降采样，但违规点和违规区间不得因降采样消失。

## 16. 已确认的结论边界

1. Ay 只有 `abs(Ay_radar - Ay_truth) ≤ 1m/s²` 一个评判指标，不使用准确率和连续三帧规则；
2. Dx 20–50m 的连续三帧限值是固定 `1.5m`；
3. 一个距离段少于3个有效样本时，该区间不出具结论；若完整曲线涉及该区间，整体也不出具结论；
4. 匹配覆盖率仅展示，不参与通过/不通过判定；
5. 跨距离段不打断完整曲线中的连续三帧关系；
6. 完整曲线内任意一个可评估距离段失败，则当前物理量整体失败；
7. 暂不要求在导出报告中增加配置版本、算法版本或数据文件校验信息。
