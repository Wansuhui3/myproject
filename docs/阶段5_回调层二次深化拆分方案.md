## 三、拆分设计

### 1. wave_callbacks.py（1333 行 → 4 个模块）

```
wave_helpers.py           ~80 行  物理量发现/统计/_get_non_highlight_shapes
                                  （含测试引用的 _discover_quantity_columns、
                                   _ensure_valid_quantities）
wave_views.py            ~250 行  _build_trajectory_table / _build_title_bar /
                                  _target_* 系列 / _build_id_list_html（纯渲染）
wave_upload_callbacks.py ~530 行  数据加载域回调：on_radar_change_label /
                                  on_radar_change_clear / on_upload_csv /
                                  on_timestamp_input / refresh_quantity_options /
                                  on_wave_clear
wave_callbacks.py        ~480 行  交互域回调：on_id_click / on_trajectory_select /
                                  on_quantity_change / on_box_select /
                                  on_clear_box_select / 摘要快照两回调
```

> 与讨论稿的差异：实测回调体约 1000 行，单一文件无法满足 ≤550 目标，
> 故按"数据加载 / 交互"拆为两个回调文件。

### 2. comparison_callbacks.py（1327 行 → 6 个模块）

```
cmp_mode_callbacks.py     ~150 行  [C0] on_cmp_clear + [C1] _make_cmp_upload /
                                   on_mode_switch
cmp_upload_callbacks.py   ~330 行  [C2] on_cmp_upload（统一上传：解析+缓存+
                                   预览+ID发现）
cmp_mapping_callbacks.py  ~450 行  [C2a] 映射配置回调×4（render_cmp_preview_summary /
                                   on_cmp_mapping_sources / render_cmp_mappings /
                                   on_cmp_mapping_edit）+ 解析 helpers×8
                                   （_cmp_resolve_mappings、_cmp_mapping_chart_config 等）
cmp_preview_render.py     ~470 行  纯渲染：占位组件 / 预览卡片 / ID 列表渲染 /
                                   _build_cmp_config_with_ids / 时间范围格式化（无回调）
comparison_callbacks.py   ~150 行  [C3] on_cmp_id_select + [C5] on_cmp_mapping_change
                                   + 包内聚合再导出
```

依赖方向（无环）：

```
wave_upload_callbacks → wave_helpers, wave_views
wave_callbacks        → wave_helpers, wave_views
cmp_upload_callbacks  → cmp_preview_render
cmp_mapping_callbacks → cmp_preview_render
comparison_callbacks(C3/C5) → cmp_preview_render, cmp_mapping_callbacks
performance_callbacks → cmp_mapping_callbacks（替代原 → comparison_callbacks）
纯渲染模块（*_views / *_render）不得导入任何回调模块
```
