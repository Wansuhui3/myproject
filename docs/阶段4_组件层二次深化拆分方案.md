## 一、背景与现状

阶段 3 已完成组件层按功能域的一次拆分（layout 三文件、stats_panel 两域、chart_common/panel_common 工具层）。
拆分后盘点，仍有两个文件体量偏大、职责混杂：

| 文件 | 行数 | 现存问题 |
|---|---|---|
| comparison_charts.py | 643 | 混杂 4 类职责：时间格式化、雷达中断检测、3 种子图构建器、主编排 |
| performance_panel.py | 376 | 表格渲染与快照摘要两种职责混杂 |

其余组件文件均已达标：layout.py 91 / layout_wave.py 171 / layout_comparison.py 213 /
graph_builder.py 279 / chart_common.py 95 / panel_common.py 26 /
wave_stats_panel.py 134 / comparison_stats_panel.py 54。

## 二、目标

- 单文件收敛到 ≤350 行、单一职责
- **纯代码移动，零行为变化**：图表渲染、交互、悬浮框格式、测试断言全部不变

## 三、拆分设计

### 1. comparison_charts.py（643 行 → 4 个模块）

```
comparison_time.py        ~50 行   _fmt_ts / _fmt_clock / _fmt_ts_vec
                                   （本地时区口径 + Windows epoch 兜底，唯一出处）
radar_gap.py              ~90 行   _find_radar_gap_indices / _insert_radar_gap_breaks
                                   （雷达中断检测与断线插入，必须在显示降采样前调用）
comparison_subplots.py   ~330 行   _build_overlay_subplot / _build_error_subplot
                                   / _build_scatter_subplot（从编排器内联分支抽出）
                                   / _add_fail_highlights
comparison_charts.py     ~200 行   build_comparison_subplots 编排器（数据准备、
                                   中断边界并入显示索引、RTK 曲线采样、循环分派）
```

依赖方向（无环）：

```
comparison_charts → comparison_subplots → (radar_gap, comparison_time, chart_common)
```

### 2. performance_panel.py（376 行 → 2 个模块）

```
performance_panel.py     ~200 行   render_performance_table / render_performance_body
                                   / 状态单元格与限值格式化
performance_summary.py   ~180 行   render_performance_distance_summary
                                   / render_performance_snapshot_summary
                                   （快照式摘要，与波动分析摘要同款交互）
```

### 3. 不动的部分（已达标）

layout 家族、graph_builder、chart_common、panel_common 均不再调整。

## 六、风险与对策

- **编辑器缓冲区回滚**（阶段 3 实际踩坑：graph_builder / comparison_charts 的编辑曾被
  旧缓冲区静默覆盖）：每步编辑后立即在磁盘上 grep 复核最终状态，发现回滚即刻重写
- `_fmt_ts_vec = np.vectorize(_fmt_ts)` 必须与 `_fmt_ts` 同模块定义，避免跨模块依赖
- 散点分支函数化是唯一"改结构"点：仅移动代码并补 `_build_scatter_subplot` 签名，
  不改任何绘制参数与配色
