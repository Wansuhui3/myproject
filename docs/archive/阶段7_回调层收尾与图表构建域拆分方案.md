## 二、拆分设计

### 步骤 1：`callbacks/performance_callbacks.py`（559 → 4 模块，原文件删除）

| 新模块 | 职责 | 迁入内容 |
|---|---|---|
| `perf_shared.py` | 性能域共享 helpers（不导入回调模块） | `_parse_segment_key`、`_perf_summary_source_key`、`_perf_summary_snapshot_label`、`_selected_radar_filename` |
| `perf_run_callbacks.py` | [C4] 执行对齐域 | `_build_perf_panel`、`update_selected_segments`、`on_cmp_run`（含合并段逻辑） |
| `perf_panel_callbacks.py` | [C4a/b/c] 验收面板域 | 摘要快照增删/渲染、指标切换、折叠切换 |
| `perf_export_callbacks.py` | [C6] 导出域 | 导出对齐+性能验收工作簿 |

兼容性：全仓唯一外部引用是 `callbacks/__init__.py` 的
`from .performance_callbacks import _selected_radar_filename`（测试不直接导入
该模块）——更新 `__init__.py` 后原文件删除，不留 shim。

### 步骤 2：`components/comparison_subplots.py`（409 → 2 模块）

| 新模块 | 职责 | 迁入内容 |
|---|---|---|
| `comparison_overlay.py` | 叠加主图构建 | `_add_fail_highlights`、`_build_overlay_subplot` |
| `comparison_subplots.py`（保留） | 误差/散点子图 | `_build_error_subplot`、`_build_scatter_subplot` |

兼容性：唯一调用方 `comparison_charts.py` 的 `_build_overlay_subplot` 导入
改到新模块；`test_comparison_charts.py` 只用 `build_comparison_subplots`，
测试零改动。
